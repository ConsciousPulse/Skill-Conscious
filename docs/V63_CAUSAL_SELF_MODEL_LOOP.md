# V63 — Causal self-model loop

## Question

Can the organism's semantic self-representation become part of a recurrent
action-conditioned loop in which a prior trajectory changes the next self-model,
that self-model changes internal dynamics, and the resulting state changes the
next trajectory selection?

This is a direct extension of V62 from a one-step intervention to a recurrent
loop.

## Protocol

Each replicate starts from one persisted warmup state and is cloned into four
matched arms:

1. self-model selection + self-model bridge OFF;
2. self-model selection + self-model bridge ON;
3. random selection + self-model bridge OFF;
4. random selection + self-model bridge ON.

The deterministic provider emits a different semantic SELF_MODEL string based
on the previous selected action:

- previous +1 -> continuity-oriented self-model;
- previous -1 -> exploratory/divergent self-model;
- no previous action -> neutral base self-model.

Semantic memory is held outside the dynamic bridge so the intervention isolates
the self-model pathway.

Each cycle is:

```
previous action
      |
      v
next semantic SELF_MODEL
      |
      v
self-model continuity bridge
      |
      v
internal dynamic state
      |
      v
self-model trajectory selection
      |
      +------------------+
                         |
                         +----> next cycle
```

The post-hoc oracle evaluates both candidate signals after the self-model update
and never participates in selection.

## Primary endpoints

- bridge ON vs OFF regret for self-model selection;
- self-model vs random regret with the bridge ON;
- paired oracle-hit differences.

## Secondary endpoints

- fraction of runs that traverse both action branches;
- action-conditioned self-model bridge signal difference;
- persistence of semantic self-model versions through the loop.

## Why this matters

V62 established that semantic self-representation can causally affect internal
numerical dynamics in a matched one-step intervention. V63 asks whether that
causal pathway remains active when the self-model is itself generated by the
organism's prior trajectory and fed back into future trajectory selection.

A positive result would establish a stronger recurrent computational property.
A null result would still identify where causal self-model feedback fails.

## Evidence boundary

The provider is deterministic and synthetic. The protocol tests recurrent
computational coupling and selection behavior, not phenomenological
consciousness or subjective experience.
