# Base documental

## 1. Manifiesto Matemático del Ser

El manifiesto define, entre otros principios:

- el ser como relación estable;
- los números fundamentales como estructuras invariantes y no simplemente cantidades;
- la realidad como iteración de relaciones;
- la dinámica como precedente del tiempo;
- la topología como elemento más fundamental que la forma;
- la vida como dinámica sostenida;
- la conciencia como sistema que se recorre a sí mismo;
- la continuidad de identidad frente al cambio.

Este documento es la fuente primaria para la ontología conceptual del proyecto.

## 2. TCF

La Teoría de Continuidad Fundamental aporta una gramática dinámica que el proyecto explora como herramienta computacional:

- modos y operadores dominantes;
- dinámica triádica;
- memoria de trayectoria;
- regímenes;
- transiciones críticas;
- términos de cruce;
- atractores y separatrices.

En este repositorio, esas ideas se tratan como hipótesis de diseño y no como evidencia automática de consciencia.

La integración detallada se documenta en [TCF — Teoría de Continuidad Fundamental](fundamentos/TCF.md).

## 3. Trabajo computacional previo

Los experimentos previos asociados al proyecto ya exploraron:

- memoria;
- histéresis;
- presión acumulada;
- estados intermedios;
- transición de régimen;
- selección topológica;
- adaptación bajo perturbación.

Consciencia para IA reúne esas ideas alrededor de un objetivo único: construir una IA persistente.

## 4. Regla de trazabilidad

Cuando una implementación se inspire en una idea del material fuente, debe anotarse:

- qué principio se toma;
- qué parte se formaliza;
- qué observación se espera;
- qué resultado podría falsarlo.

No se deben convertir metáforas en hechos físicos sin una prueba independiente.
