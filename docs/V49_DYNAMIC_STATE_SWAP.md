# V49 — Matched Dynamic-State Intervention

## Question

Does the persistent organism change its response to the same probe when the
stored dynamic state coordinate changes while persistent memory and the rest of
the receiver state remain fixed?

## Intervention

Two byte-identical receiver databases are created.

- DYNAMIC_LOW: dynamic_state = -0.8
- DYNAMIC_HIGH: dynamic_state = +0.8

Only the stored dynamic_state coordinate is intervened on. The derived attractor
distance is recomputed consistently; memory, pressure, dynamic step count, event
stream, self-model, last thought and memory content are held fixed.

The context uses event_limit=0 and memory_limit=1.

## Interpretation

A choice change under the matched intervention is evidence that the numerical
dynamic state exposed by the organism architecture causally influences the tested
response.

This does not establish consciousness or subjective experience.
