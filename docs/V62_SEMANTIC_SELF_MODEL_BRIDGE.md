# V62 — Semantic self-model causal bridge

## Question

Can a semantic self-model maintained by the organism become a causally active component of its internal dynamics, rather than remaining only descriptive text?

## Intervention

The experiment crosses:

- self-model content A vs B;
- semantic self-model bridge OFF vs ON.

Everything else is matched from the same persisted base state. Memory content is held constant.

## Expected causal chain

```text
self-model generated by organism
          │
          ▼
continuity evaluation
          │
          ▼
self-model semantic signal
          │
          ▼
internal dynamics
          │
          ▼
new persistent state
```

Bridge OFF is the isolation control: changing self-model text alone must not alter the dynamic state.

Bridge ON tests whether the self-model difference is actually transduced into the organism's internal numerical state.

## Significance

V62 moves the project beyond a self-model that merely predicts numeric state. It tests whether the organism's semantic representation of itself can enter the causal loop that changes its future internal state.

## Evidence boundary

This is a deterministic computational intervention. It does not establish phenomenological consciousness or subjective experience.
