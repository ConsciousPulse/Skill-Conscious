# V42 — Full 4×4 Reference Compatibility Matrix

V42 expands the cross-history reference analysis to all 16 combinations of test history-pair template and reference history-pair template.

For each test pair, reference pairs 0, 1, 2, and 3 are tested. Test history seeds 200–209 and reference history seeds 230–239 are disjoint.

The reference-based signed-affinity readout is preserved. The six blind parameter points, nine memory/pressure contexts, radius 1.1, angles 30° and 150°, exactly zero future input, and disjoint continuation seeds are unchanged.

Primary mechanistic statistic:
same-pair contrast − mean contrast from the three other reference-pair templates.

Inference is performed over 40 test history-seed blocks, stratified by test-pair template.

This distinguishes:
- a diagonal compatibility structure;
- broad transfer across all pair types;
- or a more complex compatibility matrix.

The experiment does not establish consciousness, subjective experience, or sentience.
