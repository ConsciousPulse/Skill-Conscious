# V28 — Context Transport of State Geometry

V28 asks whether the state-geometry effect survives when the same donor state is transplanted into receiver contexts generated from different histories.

Three receiver contexts are used:
0. zero history,
1. all-positive history,
2. independent 50/50 random-sign history.

For each receiver context, local A/B reference continuations are generated under the same receiver memory/pressure context and the corresponding donor state pair. The intervention then changes only the donor state geometry by radius (0 or 1.1) and angle (0, 90, 180).

Six fixed V12 blind parameter points, four history pairs, and seeds 30–39 are used. Future input is exactly zero.

The analysis is local to each receiver context and therefore does not assume that an identity learned in one context has the same raw trajectory scale in another.

This is a causal transportability test of the computational state representation. It does not establish consciousness or subjective experience.
