# V29 — Auxiliary Context Isolation

V29 isolates memory and pressure as nuisance/context variables.

The receiver state is fixed to the common A/B midpoint in every condition. Only one auxiliary component is changed at a time:
- BASE: common memory + common pressure.
- MEM_A / MEM_B: donor-A or donor-B memory, with state and pressure held common.
- PRESS_A / PRESS_B: donor-A or donor-B pressure, with state and memory held common.

The donor state geometry is fixed at radius 1.1 and angles 0°, 90°, 180°. Future input is exactly zero.

The 0° condition is a local-reference control. The primary mechanistic measurements are signed affinity at 90° and 180°, where negative signed affinity indicates antipodal reversal relative to the donor identity.

The experiment is designed to separate state geometry from auxiliary context dependence. It does not establish consciousness or subjective experience.
