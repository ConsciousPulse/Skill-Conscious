## Interpretation

The response changes substantially with orientation even though the norm is preserved. The strongest original-identity region is near 0°/345°, while the strongest opposite-identity region is near 150°–180°.

The profile is not a perfect sinusoid: several intermediate angles produce local departures. That irregularity is consistent with the underlying nonlinear dynamical map and should be characterized rather than smoothed away.

Because the same pattern was reproduced across six blind parameter points, the result is not specific to one tuned parameter setting.

## Main finding

V23 strengthens V22 by resolving the response at 15-degree increments. The recurrent state's identity signal is organized geometrically in its two-dimensional temporal state space, with substantial directional dependence under an equal-norm constraint.
