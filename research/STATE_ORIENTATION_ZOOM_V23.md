# V23 — Angular Zoom of State Orientation

V22 found a strong equal-norm dependence on state orientation at 45-degree increments. V23 performs a 15-degree sweep over the full 360-degree circle across the same six blind parameter points.

The donor state deviation vector is rotated around the common receiver context while preserving its Euclidean norm. Identity is scored against intact donor/opposite references.
