# V45 — Reference-Free Memory Under a Common Novel Probe

V45 tests whether retained internal history changes the processing of a new external input.

Each of four history templates is established first. Every history then receives the same deterministic novel probe. The probe is identical across all classes, so current external input does not identify the class.

A leave-one-parameter-out classifier is trained from clean runs and sees only the future state trajectory. It never receives memory or pressure.

For held-out parameter points, memory from a donor history class is substituted while receiver state and pressure are held fixed. The primary statistic is the paired change in donor-minus-receiver class probability relative to the intact receiver.

Pressure replacement and state replacement are controls.

This tests context-dependent processing of a common subsequent stimulus. It remains a computational dynamics test and does not establish consciousness, subjective experience, sentience, or phenomenological awareness.
