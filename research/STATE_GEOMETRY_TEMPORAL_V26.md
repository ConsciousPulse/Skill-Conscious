# V26 — Temporal Persistence of State Geometry

V26 tests whether the directional state code observed in V24/V25 remains causally expressed across successive zero-input continuation windows.

Conditions:
- six fixed V12 blind parameter points,
- four history pairs,
- seeds 10–19,
- common A/B receiver memory and pressure,
- future input exactly zero,
- state-deviation radius 0.0, 0.5, and 1.1,
- angles 0°, 90°, and 180°,
- eight consecutive 15-step continuation windows.

Primary output is identity accuracy per temporal window.

Radius 0 is a null condition. Radius 0.5 samples the established sub-maximal directional regime. Radius 1.1 samples the V25 peak-radius regime without changing parameter points or the analysis rule.

The experiment is descriptive and mechanistic. It does not establish consciousness or subjective experience.
