# V33 — Paired Angular Contrast and Permutation Null

V33 treats each parameter × history-pair × history-seed × memory × pressure context as a matched unit.

The primary endpoint is the continuous signed-affinity contrast:
**30° − 150°**.

The null hypothesis is generated by randomly swapping the two angle labels within each matched unit, preserving all nuisance/context structure.

Five independent continuation-noise seeds are used to construct the A/B reference ensemble and five independent test continuation seeds are used for each angular condition.

Seeds are independent of V32.

The experiment asks whether the directional angular difference survives a paired permutation null after preserving receiver context. It does not establish consciousness or subjective experience.
