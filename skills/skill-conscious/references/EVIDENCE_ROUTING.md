# Evidence Routing Reference

For any claim about Skill-Conscious experiments:

1. Start with `research/ORGANISM_RESULT_LEDGER.md`.
2. Open the matching `docs/Vxx_*.md`.
3. Inspect `experiments/*vxx*.py` only if implementation details are needed.
4. Inspect `tests/*vxx*.py` when verifying executable assertions.
5. Inspect `.github/workflows/*vxx*.yml` when verifying CI execution.

## Interpretation boundary

Experimental results describe computational behavior under defined protocols and environments.

They do not automatically establish subjective experience or phenomenal consciousness.

Null and negative results are first-class evidence.
